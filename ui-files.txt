REDESIGN & FULLY IMPLEMENT FILES EXPLORER

Tujuan utama:
Ubah halaman Files menjadi Files Explorer yang jauh lebih rapi, compact, modern, dan usable. Gunakan desain target berikut sebagai acuan visual utama:

- Layout harus mengikuti konsep UI target:
  - Tab/session selector di bagian atas
  - "Local" harus SELALU tersedia dan selalu menjadi item pertama.
  - Setelah Local, tampilkan seluruh sesi SFTP yang sedang aktif/tersedia.
  - User dapat berpindah antara Local dan banyak sesi SFTP dengan cepat.
  - Toolbar file explorer berada tepat di bawah session/tab selector.
  - File/folder list menggunakan card/container yang clean, dark, rounded, dan compact.
  - Bottom navigation tetap tersedia pada mobile.
- Jangan hanya melakukan perubahan kosmetik. Implementasikan Files Explorer secara penuh dan benar-benar fungsional.

==================================================
1. SESSION / LOCATION NAVIGATION
==================================================

Buat sistem location/session selector:

[ Local ] [ Server 1 ] [ Server 2 ] [ Server 3 ] ...

Rules:

1. "Local" HARUS SELALU ditampilkan.
2. Local selalu berada di posisi paling kiri/pertama.
3. Local digunakan untuk browsing file dan folder filesystem lokal.
4. Setelah Local, tampilkan sesi/server SFTP.
5. Jumlah sesi SFTP tidak dibatasi secara desain.
6. Jika sesi terlalu banyak:
   - horizontal scroll pada mobile
   - jangan membuat header menjadi berantakan
   - gunakan compact session chips/tabs
   - session yang aktif harus sangat jelas terlihat.
7. Setiap SFTP session harus memiliki status:
   - Connected
   - Connecting
   - Disconnected
   - Error
8. Gunakan indicator warna/status yang jelas.
9. User dapat berpindah session tanpa kehilangan state folder dari session sebelumnya.
10. Setiap session menyimpan:
    - current path
    - selected files
    - sorting
    - view mode
    - scroll position jika memungkinkan.

Contoh:

Files

[ 🟢 Local ] [ 🟢 Server · 25 ] [ 🟢 VPS ] [ + ]

/     [ New Folder ] [ Upload ] [ Transfer ] [ Refresh ]

------------------------------------------------

Parent directory
boot
dev
etc
home
...

Jika session terlalu banyak:

[ Local ] [ Server 1 ] [ Server 2 ] [ Server 3 ] ...
< horizontal scrolling >
